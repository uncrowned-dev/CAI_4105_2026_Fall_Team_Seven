# CAI 4105 Fall 2026, Team Seven

Each challenge has its own folder with its data, notebooks, and a README.

| Folder | Challenge | Type |
|---|---|---|
| [`challenge1/`](challenge1/) | Predict the monthly rent of an apartment | Regression |
| [`challenge2/`](challenge2/) | Predict whether an online shopping visit ends in a purchase | Classification |

## Setup

```bash
pip install -r requirements.txt
```

Then open the notebook inside the challenge folder you want. Notebooks read their data from their own folder, so run them from there.

## Working together

- Make a new branch for each change. Do not work straight on `main`. Open a pull request into `main` when a change is ready.
- Keep each challenge's files inside its folder.
- Rerun the whole notebook before committing so the saved results match the code.
- Write short commit messages that say what changed and why.
